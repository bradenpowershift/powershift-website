# Powershift Energy Co — Website

Temporary 5-page static website for [powershiftenergy.com.au](https://powershiftenergy.com.au). Connects Australian homeowners with CEC-accredited solar, battery and EV charger installers via free quote forms.

## Pages

| Page | Purpose | Form Endpoint |
|------|---------|---------------|
| `index.html` | Hub / homepage | — |
| `solar.html` | Solar lead capture | Formspree `xyklgzqn` |
| `battery.html` | Battery lead capture (lead offer) | Formspree `xvzdpgje` |
| `ev-charger.html` | EV charger lead capture | Formspree `mbdqrlnl` |
| `electricians.html` | B2B installer partner application | Formspree `mjgjbkny` |

## Tech Stack

- Vanilla HTML, CSS, JavaScript (no frameworks)
- Google Fonts (DM Sans)
- Formspree for form handling
- Hosted on Netlify
